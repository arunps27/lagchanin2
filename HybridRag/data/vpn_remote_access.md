# Remote Access and VPN Guide
Employees working remotely must connect through the corporate VPN using the WireGuard client. Multi-factor authentication via a hardware security key (FIDO2) is mandatory for all VPN sessions. Split tunneling is disabled; all traffic is routed through the corporate gateway at vpn.example-corp.net on UDP port 51820. Sessions time out after 12 hours of inactivity and devices must have full-disk encryption and an up-to-date endpoint agent. If the VPN fails to connect, verify that UDP 51820 is not blocked by the local network, then contact the IT service desk at extension 4400.
