# Security Incident Response Runbook
Severity SEV-1 incidents include confirmed data exfiltration, ransomware, or compromise of production credentials. For a SEV-1, the on-call engineer must page the Incident Commander within 15 minutes and open a dedicated war-room channel. Containment steps: revoke exposed API keys, rotate secrets in the vault, isolate affected hosts using the EDR console, and snapshot disks for forensics. Customers must be notified within 72 hours of confirmed personal data breach, in line with GDPR Article 33. A blameless post-incident review must be published within 5 business days. SEV-2 incidents involve partial service degradation without data loss and require acknowledgement within 1 hour.
